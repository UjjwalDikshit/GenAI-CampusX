📌 LangChain — format() / format_prompt() vs invoke()
1. prompt.format() / prompt.format_prompt()
Purpose:
Fill in placeholders in a prompt template with actual values.
Does NOT call the LLM — only prepares the prompt.
When to use:

Inspect/debug the prompt before sending to LLM.
Reuse the formatted prompt later.
Manually control the LLM call.

Example:
Pythonfrom langchain.prompts import PromptTemplate

prompt = PromptTemplate(
    input_variables=["product", "features"],
    template="Write a description for {product} highlighting {features}."
)

# Returns a plain string
formatted_str = prompt.format(
    product="Smartphone",
    features="Lightweight, Responsive"
)
print("format() output:", formatted_str)

# Returns a PromptValue object (for chains)
formatted_prompt_value = prompt.format_prompt(
    product="Smartphone",
    features="Lightweight, Responsive"
)
print("format_prompt() output:", formatted_prompt_value)


2. prompt.invoke()
Purpose:
Formats the prompt and passes it to the next step (e.g., an LLM) in one go.
Part of LangChain's Runnable interface.
When to use:

Using LangChain pipelines/chains.
Want to execute the prompt directly without manual formatting.
Integrating with other Runnable objects.

Example:
Pythonfrom langchain.prompts import PromptTemplate
from langchain.chat_models import ChatOpenAI

prompt = PromptTemplate(
    input_variables=["product", "features"],
    template="Write a description for {product} highlighting {features}."
)

llm = ChatOpenAI(model="gpt-3.5-turbo", temperature=0)

# Combine prompt and LLM into a chain
chain = prompt | llm

# invoke() formats + sends to LLM
response = chain.invoke({
    "product": "Smartphone",
    "features": "Lightweight, Responsive"
})
print("invoke() output:", response.content)
